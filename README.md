# Teachable Machines


## Objective

Train an image recognition model using Google Teachable Machine and test it using Anaconda and Visual Studio Code.


## Steps

### 1. Create and Train the Model
 First, we go to Teachable Machine website  and create to classes at least and named each class that what we want to compare first class "Mobile Phone" and second class "Tablet". Then add as many images as you can to each class to improve the accuracy of the test. After that, press Model training and put extra image to test what it is "Mobile Phone" or "Tablet".

### 2. Export the Model
 Next, click Export Model, choose TensorFlow, and then select Keras to download the trained model. After downloading, copy the Python code provided by Teachable Machine.

### 3. Create an Anaconda Environment
 Open Anconda and go to the Enviroments tap. Click Create to initialize a new environment.

- Enter a name for the environment.
- Select Python 3.10.20 as the Python version.
- Click Create.

After the environment is created, open the terminal and install the required libraries using the following commands:

pip install opencv-python
pip install tensorflow==2.12.1
pip install pillow numpy

### 4. Test the Model in VS Code
 Open Visual Studio Code and place the following files in the same folder:

- keras_model.h5
- labels.txt
- The test image
- A new Python file named test.py

Copy the Python code generated by Teachable Machine and paste it into test.py.

Then, replace the image path on line 20 with the path of the image you want to test.

Finally, open the terminal in VS Code and activate your Anaconda environment. Run the Python script to test whether the model can correctly classify the image.
