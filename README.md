# Voice AI Assistant

Listens to your voice, replies with Cohere, then speaks the answer.

**Flow:** Speech → Text → Cohere → Speech

## Install Requirements

- pip install RealtimeSTT
- pip install RealtimeTTS
- pip install cohere
- pip install python-doten
- Cohere API key
- Microphone 

## Setup

1. Open the project folder


2. Create a `.env` file:

```env
COHERE_API_KEY=your_api_key_here
```

3. create python code
4. Run:
open cmd inside the folder in VS code and use this prompt to run the program.
```bat
python AiVoice.py
```

Speak when you see `Speak now...`. Press `Ctrl + C` to stop.
