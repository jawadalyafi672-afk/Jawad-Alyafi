# Fruit Object Recognition


## Objective

Make a project using OpenCV for Fruit Object Recognition.


## Steps

### 1. Open Anaconda and install OpenCV packages.

<img width="1919" height="544" alt="image" src="https://github.com/user-attachments/assets/edf6e3ef-e353-4712-b9a4-134eaf3c3adc" />

### 2. Launch VS Code from Anaconda to connect your Kernal with your opencv code.

 <img width="1919" height="979" alt="image" src="https://github.com/user-attachments/assets/ba81a860-87bd-4df2-8639-0b6adcf06602" />

### 3. Add the fruit image and create the recognition notebook

- Put the image `Fruit.webp` in the project folder.
- Create a notebook file named `Fruit Object Recognition.ipynb`.
- Write the OpenCV code that:
  - reads the image
  - separates the fruits from the background
  - detects each fruit using contours
  - recognizes the fruit type by color and shape (Banana, Grapefruit, Watermelon, Orange)
  - draws a bounding box and label on each fruit
  - 
### 4. Open the notebook and select the Anaconda kernel

Open `Fruit Object Recognition.ipynb` in VS Code and make sure the Python kernel from Anaconda is selected.

<img width="1621" height="646" alt="image" src="https://github.com/user-attachments/assets/3988dcde-8bc1-42a3-9c5a-4ab3002db9ae" />

### 5. Run the Program

Run the Python file. A window will open showing the detected fruits with their labels.
